PowerToys Command Palette extension · Windows

Dev Launchpad

Open repositories, developer apps, local dev servers, bookmarks and your own commands from the PowerToys Command Palette (Win+Alt+Space), with branch, git status and tech stack shown for every repo.

Simulated Nothing on your computer is launched. The palette below is an HTML re-creation of Dev Launchpad's pages, running the extension's search, sorting and command logic re-implemented in JavaScript. The repositories are a fictional sample under C:\Projects, the GitHub account is made up, and the sync terminal output is a scripted transcript. Every action writes what the real extension would run to the launch log instead of running it. The real extension needs Windows and PowerToys (see what it requires).

Try it

Click into the palette and type. ↑/↓ to move, Enter to run the primary action, Ctrl+K for more actions, Esc or Backspace on an empty search to go back. On a phone, tap an item; tap ⋯ for more actions.

      What is real and what is simulated

      Taken from the extension's code

      • The nine top-level commands, every page title, item title, subtitle and toast message.
      • The default config.json, its field names, and how missing or blank entries are skipped.
      • Repository search over name, path, tech stack and the status words dirty, unsynced, ahead, behind, stashed, stash.
      • The subtitle format [branch ↕ * ~N] (Stack) path and the ordering: pinned, then recent, then name.
      • The repo context menu, including Open on GitHub vs Open Remote in Browser and Merge Requests for GitLab.
      • Clone URL parsing (https://, git@, ssh://) and the destination path.
      • The six custom command types: url, folder, command, terminal-in-folder, wsl-command, ssh.
      • The exact command lines in the launch log, including wt -d "…" for Windows Terminal.

      Simulated for this page

      • Nothing is launched, opened, cloned, checked out or copied. The launch log shows what would happen.
      • The repositories, branches, remotes and git status are a fictional sample. The real extension reads them from .git folders on disk.
      • The folders that "exist" are just the sample's. A path outside it gives the real "Folder not found" or "Projects folder not found" result.
      • The Sync All GitHub Repos terminal output is a scripted transcript for a made-up account. The script text shown is the real generated script.
      • config.json lives in this page's memory. Reloading the page resets it.
      • Only Dev Launchpad's commands are shown. The real palette lists every installed extension, and it does its own matching on the top-level list.

      What the real thing requires

      1. Windows 10 or 11 (version 19041 or later) with PowerToys installed and Command Palette turned on in PowerToys Settings.
      2. The extension, either built and deployed from source with Visual Studio 2022 or later (DevLaunchpad.sln, F5), or sideloaded from the unsigned x64/arm64 .msix that the MSIX workflow builds (you sign it with a certificate you trust). A Microsoft Store listing is planned but not published yet.
      3. In the palette, run Reload extensions, then type dev or a command name.
      4. For Sync All GitHub Repos: the GitHub CLI (gh), signed in with gh auth login, and git on PATH. Dev Launchpad stores no credentials.
      5. Your settings live in config.json under the package's LocalState\DevLaunchpad folder. The Configuration page shows the exact path.

      See the README for installation and the full configuration reference.

      # Dev Launchpad - Sync All GitHub Repositories
# Auto-generated. Clones repositories you do not have locally and fast-forward-pulls the rest.
#
# Requirements:
#   * GitHub CLI (gh)  - https://cli.github.com
#   * An authenticated session - run 'gh auth login' once.
#   * git available on PATH.
#
# Runs against the current directory (Dev Launchpad launches it in your projects folder).

$ErrorActionPreference = 'Continue'

function Test-ToolPresent([string] $name) {
    return [bool] (Get-Command $name -ErrorAction SilentlyContinue)
}

if (-not (Test-ToolPresent 'gh')) {
    Write-Host 'GitHub CLI (gh) is not installed or not on PATH. See https://cli.github.com.' -ForegroundColor Red
    exit 1
}
if (-not (Test-ToolPresent 'git')) {
    Write-Host 'git is not installed or not on PATH.' -ForegroundColor Red
    exit 1
}

Write-Host 'Checking GitHub CLI authentication...' -ForegroundColor Cyan
gh auth status 1>$null 2>$null
if ($LASTEXITCODE -ne 0) {
    Write-Host "Not signed in to GitHub. Run 'gh auth login' first." -ForegroundColor Red
    exit 1
}

Write-Host 'Fetching repository list...' -ForegroundColor Cyan
$repos = gh repo list --limit 1000 --json nameWithOwner --jq '.[].nameWithOwner'
if ($LASTEXITCODE -ne 0) {
    Write-Host 'Failed to list repositories.' -ForegroundColor Red
    exit 1
}

$cloned = 0
$updated = 0
$failed = 0

foreach ($repo in $repos) {
    if ([string]::IsNullOrWhiteSpace($repo)) { continue }

    # Local folder matches gh's default clone target: the repository name.
    $dir = $repo.Split('/')[-1]

    if (Test-Path -Path (Join-Path $dir '.git')) {
        Write-Host "updating $dir" -ForegroundColor Yellow
        git -C $dir pull --ff-only
        if ($LASTEXITCODE -eq 0) { $updated++ } else { $failed++ }
    }
    else {
        Write-Host "cloning $repo" -ForegroundColor Green
        gh repo clone $repo
        if ($LASTEXITCODE -eq 0) { $cloned++ } else { $failed++ }
    }
}

Write-Host ''
Write-Host "Done. Cloned $cloned, updated $updated, failed $failed." -ForegroundColor Cyan
